# Template Orientation

This first schedule page serves as an orientation to the template itself. It is an example of how a date-specific page should look when used as a course meeting or workshop page.

## What this page is for

Use schedule pages to organize the content for a single class meeting or workshop. Keep each page focused on what the instructor and students need to do during that moment in the semester.

## Recommended structure

A good schedule page usually contains:

- a short title
- a list of learning goals or intended outcomes
- a brief agenda
- a list of deliverables, reading, or preparation steps
- a short set of instructions for what happens next

## What to customize for your course

When you adapt the template, replace the content here with your own:

- session goals
- class activities
- required reading or preparation
- assignments or milestones
- next steps for students

## Suggested instructor actions

Before using the template, consider the following:

1. Determine the semester calendar.
2. Decide which class meetings need dedicated pages.
3. Write the first few schedule pages so the structure is clear.
4. Generate the schedule data and review warnings.

## Before the next class

- confirm the semester calendar is accurate
- confirm the schedule filenames match the required pattern
- preview the site locally
- update any class pages that still contain template placeholder text
