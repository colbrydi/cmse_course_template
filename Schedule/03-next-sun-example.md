# Example: Due on the First Sunday After Class 03

This page demonstrates the `03-next-sun-example.md` naming pattern. It is intended to show how to schedule something for the first Sunday after the third class meeting.

## Why this matters

The filename tells the generator to start from class day 03 and then move to the next Sunday after that date. This is useful when an assignment is intentionally due after a weekend break or when you want a short reflective task to land on a more natural planning day.

## Example use case

A course might want a lightweight reflection, check-in, or planning note to appear on the next Sunday after class 03 so students have time to process the session before the next week begins.

This is the pattern you would use when the due date should not sit on the same day as the class itself, but should still remain clearly attached to that class.
