# Project Checkpoint

This is a date-offset item attached to class 03. The filename begins with `03-plus-2-`, so the generator places it two calendar days after the third class meeting.

## When to use this pattern

Choose this pattern for assignments or checkpoints that should be due shortly after a class, but not on the same day. Common examples include:

- project milestone submissions
- draft review tasks
- peer-feedback responses
- short preparation notes due a few days later

## Example

If class 03 introduces the project plan, then a follow-up checkpoint two days later is a good place to ask students to post a brief update or draft file.
