# Same-Day Check-In

This is a same-day item attached to class 03. Because the filename starts with `03-same-`, the schedule generator places it on the same calendar date as the third class meeting.

## Why this pattern is useful

Use this pattern for short actions that should happen during the same class day, such as:

- a quick reflection question
- a survey or sign-in task
- a same-day deliverable
- an in-class prompt to be completed before the next session

## Example

If you want students to submit a brief reflection immediately after discussing the project, this is the right naming pattern.
